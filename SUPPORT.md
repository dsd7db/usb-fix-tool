# Support

For non-sensitive bugs or questions, use this repository's GitHub Issues. No response-time or data-recovery service is promised.

Include the exact commit or source version, Windows/Python/PySide6 versions, whether you used source or a packaged executable, the selected tab/action, expected versus actual behavior and sanitized logs. For build issues include the build command, working directory and resolved PyInstaller version.

Do not upload disk images, recovered files, credentials or unredacted device serials. Use [SECURITY](SECURITY.md) for sensitive reports. If data is irreplaceable, stop writing and seek qualified recovery help before trying repeated repairs.

Read [usage](docs/USAGE.md), [installation](docs/INSTALLATION.md) and [safety](docs/SAFETY.md) before troubleshooting.
