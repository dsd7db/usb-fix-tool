Run the desktop application on Windows

Requires Python 3.10 or newer, an internet connection for dependency installation, and Windows 10 or 11 for USB management functions.

1. Get the repository source

Clone dsd7db/usb-fix-tool or select Code → Download ZIP on GitHub and extract it.

2. Open the desktop subdirectory

In the extracted repository, open usb-fix-tool/desktop (the repository and subdirectory share a similar name).

3. Start from source

Run run.bat to create the virtual environment and install PySide6, then launch the application. Alternatively follow the PowerShell instructions in the build guide.

4. Compile if you need a Windows executable

Run build.bat on Windows. On success, the expected output is dist/USBFixTool/USBFixTool.exe. Keep the entire output folder, not just the executable.

Data safety comes first

Capacity tests write to available space. CHKDSK modifies file-system metadata. Formatting, partition deletion, Advanced Repair and Fix Fake Drive can permanently erase data.

⚠

Back up first

Do not run repairs on irreplaceable files without an independent backup or recovery image.

▤

Verify the physical disk

Check model, disk number, size and partition against Windows Disk Management before confirming destructive actions.

◫

Different safeguards by tab

USB Partitions rechecks disk identity; Repair Tools uses simpler volume-to-disk mapping. Neither eliminates all risks.
