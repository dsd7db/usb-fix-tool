How to install

USB Fix Tool is portable. There is nothing to install — admin rights are requested only when you actually run a repair command.

Download the ZIP

Save it somewhere convenient — Desktop, Downloads, or a USB key for tech-support kits.

Unblock and unzip

Right-click the ZIP → Properties → tick Unblock, then extract the folder.

Run USBFixTool.exe

Windows will show a UAC prompt — accept it so the tool can run CHKDSK, format and diskpart on your behalf.

Pick a drive, run a fix

Start with CHKDSK. Escalate to Format or Advanced Repair only if the error persists.

Is it safe?

USB Fix Tool is a thin wrapper around commands that already ship with Windows. It does not write to the registry, doesn't phone home, and ships as a folder of normal files (not a single-file packed exe) to keep antivirus engines happy.

⚠

Read warnings carefully

Format and Advanced Repair erase the drive. The app makes you tick a checkbox before either runs.

▤

Everything is logged

Every command and its full output appear live in the console. Copy it for support if needed.

⨯

Pick the right drive

Only removable drives are listed — but always double-check the drive letter before you click.

Already lost files? Recover them first.

If your drive was formatted by accident, run a recovery scan before you write anything new to it. Recovery rates drop sharply once the drive is reused.
