Test real capacity. Fix broken USB drives.

A transparent utility that verifies your drive's true capacity with an H2testw-style write-and-verify test, exposes fake drives with a clear PASS/FAIL verdict, provides USB partition management with device-identity checks, and runs Windows' own repair commands — CHKDSK, format and diskpart — behind a clean professional interface.

View source and build steps → Read the guides

What it does

Built for suspicious marketplace drives, stuck USB sticks, RAW partitions and flash drives that suddenly show 0 bytes. Use only with backups; repair operations may change or erase storage.

✓

Real capacity test (PASS/FAIL)

Writes and verifies data in available free space to help identify fake-capacity drives — live speeds, error counts and a clear verdict.

◫

USB partition manager

Inspect, delete, create and format partitions — with removable-USB eligibility checks. Always verify the physical disk.

▣

Detect drives instantly

Lists removable volumes recognized by Windows, including their labels, file systems and sizes.

⚒

Run CHKDSK

Runs Windows CHKDSK to inspect and repair file-system errors; it can modify data and is not a recovery guarantee.

⟳

Format FAT32 / exFAT / NTFS

Quick reformat with a custom volume label when CHKDSK isn't enough.

⚙

Advanced repair (diskpart)

Cleans the disk and rebuilds the partition table for severely broken sticks.

How it works

A practical workflow for inspecting and troubleshooting a USB drive.

Plug in your USB drive

Open USB Fix Tool — it lists every removable drive Windows can see.

Pick the right repair

Back up important files first. CHKDSK may alter metadata; format or repartition only after recovery is no longer needed.

Watch the log, eject safely

Every command runs in front of you. Review the commands and their logged results before proceeding.

If your data matters, stop writing to the drive and seek qualified recovery advice before formatting or repartitioning. Recovery is not guaranteed.
