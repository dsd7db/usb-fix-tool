USB Drive Showing 0 Bytes Fix

Your 32 GB USB stick suddenly shows up with 0 bytes of total capacity. Windows can see it, but every double-click gives you "Insert a disk into drive F:". Annoying — but almost always fixable in five minutes flat.

Why does a USB drive show 0 bytes?

There are four common causes:

  1. Corrupted partition table. The drive's "table of contents" got damaged — usually from yanking it out during a write. Windows reads the table, sees nonsense, and reports zero capacity.
  2. Counterfeit / fake-capacity drive. Cheap marketplace sticks lie about their size. Once you fill the real flash, the controller starts returning errors and Windows eventually gives up and reports 0 bytes.
  3. Failed firmware update or unsafe ejection during a format. Mid-operation power loss leaves the controller in a half-erased state.
  4. Dying NAND chip. Less common, but it does happen — especially on sticks older than five years that have seen heavy use.

The first three are software problems. You can fix them at home, for free, in under five minutes. The fourth one isn't fixable — but a recovery scan can usually still pull files back.

Before you fix it: try to read the drive

Even if Windows reports 0 bytes, recovery software can sometimes read the raw flash and pull files back — but only before you run diskpart on it. If you have important data on the stick, run a recovery scan first.

Recover before you repair

Modern recovery tools scan the drive at the sector level even when Windows reports 0 bytes. Pull your files first, then fix the drive — the success rate drops dramatically once you diskpart-clean.

Fix 1 — Try CHKDSK first (rarely works, but cheap)

CHKDSK normally refuses to run on a 0-byte drive ("the type of the file system is RAW"), but it's worth a 30-second attempt: every once in a while it spots a damaged FAT and rebuilds it. 

chkdsk F: /F /R /X

If it bails out with a RAW or unrecognised-format error, move on to Fix 2.

Fix 2 — Diskpart clean and recreate (works on most drives)

This is the magic bullet for 0-byte USB sticks. Diskpart wipes the partition table, recreates a fresh primary partition spanning the full real capacity of the flash, and formats it.

This erases everything on the drive. Recover your files first if you need them.

  1. Open Command Prompt as administrator.
  2. Type diskpart and press Enter.
  3. Type list disk — find your USB stick by size. Check the size twice — choosing the wrong number wipes another drive on your PC.
  4. Run the script below, replacing N with the disk number from the previous step:
select disk N
attributes disk clear readonly
clean
create partition primary
active
format fs=exfat quick
assign
exit

After exit, Windows pops up a "Drive ready to use" notification. Open File Explorer — the stick now reports its real capacity again.

Fix 3 — Vendor "low-level format" tools (last resort)

If diskpart fails ("DiskPart has encountered an error: Access is denied" or "The media is write protected"), the controller itself is stuck. Manufacturer-specific tools can sometimes reset it:

  • SanDisk — RescuePRO and Memory Zone (mostly for cards).
  • Kingston — Format Utility on the Kingston support site.
  • Transcend / ADATA — vendor-specific format utilities, downloadable from each company's site.
  • Generic chips — there's a community-driven tool called ChipGenius that identifies the controller and points you to the matching firmware utility.

These tools talk directly to the USB controller and reset its internal state — including the read-only flag that diskpart can't clear.

Special case — counterfeit drives

A "1 TB" stick bought for $9 is almost certainly fake. Vendors flash the controller to report a huge capacity, but the actual NAND inside is 8 GB or 16 GB. The drive looks fine until you fill it past the real size — then it overwrites the start of its own data, the partition table breaks, and Windows reports 0 bytes.

A free tool called H2testw (or FakeFlashTest on Linux) writes test patterns to the entire drive and reports the real capacity. After identifying the true size, you can use diskpart to create a partition only as large as the real flash — the drive then becomes safe to use, just much smaller than advertised.

Tip. If you bought the drive recently, request a refund. A counterfeit drive will fail again — usually with the files you cared about most on it.

Quick recap

  1. If you have important files, run a recovery scan first.
  2. Try CHKDSK (almost never works, but worth 30 seconds).
  3. Use diskpart clean → create partition → format — or click Advanced Repair in USB Fix Tool.
  4. If diskpart fails, reach for the vendor's low-level format utility.
  5. If you bought the drive cheap online, test for fake capacity before trusting it again.

Frequently asked questions

My USB shows 0 bytes — does that mean the drive is dead?

Almost never. In 90%+ of cases the flash chip itself is healthy and the partition table is corrupt. Diskpart rewrites the table, and the drive's real capacity returns. A truly dead chip is obvious — Windows reports it as "unrecognised device" on every PC, plays no insert sound, and shows zero current draw on a USB power meter.

Can I fix a 0-byte USB drive without erasing it?

Sometimes yes. Try TestDisk (free, open source) before reaching for diskpart — it can rebuild the partition entry without touching data sectors. If TestDisk finds the original partition and your folders, write the recovered table back and you're done with files intact.

Why does my USB drive randomly drop to 0 bytes?

Three usual suspects: a flaky USB cable that briefly loses power mid-write, an over-aggressive antivirus product locking the drive during a scan, or a counterfeit stick that's silently overwriting its own partition table once you exceed real capacity. Test the drive with H2testw to rule out fake capacity.

What's the difference between Format and Advanced Repair in USB Fix Tool?

Format writes a fresh file-system header on the existing partition — fast, but it can't fix a broken partition table. Advanced Repair first runs diskpart clean to wipe the partition table, then creates a new primary partition spanning the full real capacity of the flash, then formats it. Use Format first; Advanced Repair when Format fails or the drive still reports the wrong size.

Can I trust low-cost "1 TB" USB drives from marketplaces?

No. Prices for legitimate 1 TB flash media start far above $9. Bargain marketplace listings are almost always counterfeit drives flashed to report a fake capacity. They work until you fill the real flash, then files start corrupting and the drive eventually shows 0 bytes. Buy from authorised resellers only.

Will diskpart erase my files permanently?

Diskpart clean wipes the partition table but doesn't touch every data sector — recovery software can usually still pull files back from the unallocated space. clean all (note the trailing word) does a full sector wipe and is unrecoverable. USB Fix Tool only ever runs the safer clean variant.
