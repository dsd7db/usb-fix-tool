USB Not Recognized Fix (Step-by-Step Guide)

Plug in a USB stick, get nothing — no drive letter, no notification, sometimes not even a beep. Below are the five fixes that solve this for the vast majority of flash drives, ordered from safest to most invasive. Try them in order.

A USB drive that "isn't recognized" can mean a lot of things in Windows: it shows up in Device Manager as Unknown Device, it appears in Disk Management without a letter, it's listed in File Explorer but throws an error on every click, or it doesn't appear anywhere at all. The good news: these are usually software-side problems and can be fixed in five to ten minutes without any paid tools.

The order below is deliberate. Each step is non-destructive until Step 5 — never jump straight to formatting unless you've copied your data first (or you accept losing it).

Step 1 — Rule out the cable, port and PC

Easily 30% of "broken USB" calls turn out to be a flaky front-panel port or a tired extension cable. Spend two minutes on this before anything else:

  • Plug the drive into a different USB port — preferably one on the back of a desktop PC, directly on the motherboard.
  • Skip USB hubs and front-panel headers for the test.
  • If you have a second computer (a laptop counts), try the drive there. If it works, the original PC's controller or driver is the culprit, not the drive.
  • Inspect the connector for bent pins or pocket lint.

Listen for the standard Windows "ding" when you plug in. If you hear nothing on any port and on any PC, you're likely dealing with a hardware failure inside the drive itself — software fixes can't bring it back, but recovery software sometimes still can.

Step 2 — Refresh the USB driver

Windows occasionally caches a stale or corrupt driver for a specific stick. Reinstalling it forces a clean enumeration:

  1. Press Win + X → Device Manager.
  2. Expand Disk drives (and Universal Serial Bus controllers).
  3. Find your drive (it may say Unknown Device). Right-click → Uninstall device.
  4. Unplug the USB stick, wait five seconds, plug it back in. Windows reinstalls the driver automatically.
Tip. If the drive shows a yellow exclamation mark, open its Properties → Driver → Update driver → Search automatically. That fixes the bulk of "Code 43" errors.

Step 3 — Assign a drive letter

Sometimes the drive mounts perfectly but Windows doesn't give it a letter — usually because another mapped drive (a network share, a Veracrypt volume) is already squatting on the next free letter. File Explorer hides drives without letters, so the stick looks invisible.

  1. Press Win + X → Disk Management.
  2. Find your USB stick by its size — it usually shows a healthy partition with no letter.
  3. Right-click the partition → Change Drive Letter and Paths… → Add → pick a free letter like F: or G:.

Or use USB Fix Tool's Assign Letter button — it runs the same diskpart commands behind the scenes.

Step 4 — Run CHKDSK to repair the file system

If the drive shows up but errors out on read ("the parameter is incorrect", "the file or directory is corrupted"), the file system is damaged but the drive itself is fine. CHKDSK rebuilds the file-system metadata in place — and almost always preserves your files. 

chkdsk F: /F /R /X

/F fixes errors, /R recovers readable information from bad sectors, and /X dismounts the volume first so other handles don't fight CHKDSK.

In USB Fix Tool, select the drive and click Run CHKDSK — the same command runs and the live output appears in the log console.

If the log says "RAW". CHKDSK refuses to fix RAW file systems. Skip ahead to our RAW USB guide — running format on a RAW drive immediately destroys recoverable data.

Step 5 — Rebuild the partition with diskpart

When CHKDSK can't help and the drive is still readable in Disk Management, the partition table itself is broken. Rebuilding it with diskpart fixes the most stubborn cases — but this erases the drive. Recover anything you need first.

You can do it manually:

diskpart
list disk
select disk N        REM N = your USB disk number
attributes disk clear readonly
clean
create partition primary
active
format fs=fat32 quick
assign
exit

Or simply click Advanced Repair in USB Fix Tool — same script, same result, with a confirmation dialog so you can't nuke the wrong disk by accident.

Why is my brand-new USB still not recognized?

  • Mass-counterfeit drives. Cheap "1 TB" sticks from random marketplaces report a fake capacity. Windows tries to write past the real flash size and the drive locks up. A full diskpart clean + format usually exposes the true size.
  • Write-protect switch. SD cards (and a few USB sticks) have a tiny lock switch on the side. If it's engaged, Windows refuses every write — including format.
  • Power-only cable. Some USB-C cables only carry power. If you're using a phone cable, swap it for a known data-capable one.

Already lost files?

If a hasty format wiped your photos, documents or videos, stop using the drive immediately and run a recovery scan first. The longer you keep writing to a drive after deletion, the lower the recovery rate — every new file potentially overwrites the old sectors.

Quick recap

  1. Try another port / cable / PC.
  2. Reinstall the USB driver in Device Manager.
  3. Assign a new drive letter in Disk Management.
  4. Run CHKDSK /F /R /X.
  5. Recover data, then rebuild the partition with diskpart.

Frequently asked questions

Why does my USB show up in Device Manager but not File Explorer?

The driver is fine but the partition either has no drive letter or is unallocated. Open Disk Management (Win + X → Disk Management) and look for the drive by its capacity. If it has a partition without a letter, assign one. If the entire disk is "unallocated", run a recovery scan first, then create a fresh partition with diskpart or USB Fix Tool's Advanced Repair.

Will CHKDSK delete my files?

No. CHKDSK with /F repairs the file-system metadata in place. It can move corrupt files into Found.000 folders, but it doesn't intentionally delete data. Format and diskpart, on the other hand, do erase the directory.

The drive works on another PC. What's wrong with mine?

Most likely a cached USB driver entry on your machine. In Device Manager open View → Show hidden devices, expand Universal Serial Bus controllers, and uninstall any greyed-out entries that match your stick. Reboot, plug back in, Windows reinstalls the driver from scratch.

Can I fix a USB drive without losing data?

Often yes — CHKDSK and TestDisk are non-destructive. But if the file system is RAW or the partition table is gone, you'll need to recover files first (with dedicated software), then repair. Never let Windows' "format the disk" prompt run on a drive whose data you still want.
