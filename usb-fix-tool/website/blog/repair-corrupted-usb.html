How to Repair a Corrupted USB Drive

A corrupted USB stick is rarely truly broken — it's a software problem that looks like a hardware one. This guide walks through the exact order of repairs to try, why each one works, and how to avoid the all-too-common "I formatted it and now my files are gone" disaster.

What "corrupted" actually means

When people say a USB drive is corrupted they usually mean one of four things:

  • You can see it but not read it. Errors like "The file or directory is corrupted and unreadable" or "The parameter is incorrect" on every double-click.
  • It mounts as RAW. Windows asks you to format before you can access it. Don't.
  • It shows the wrong size. A 32 GB stick reports as 8 MB, 0 bytes, or "200 GB" (counterfeit drives do this).
  • It's stuck read-only. Every write fails with "The disk is write-protected".

Each one has a different fix. Don't reach for the format button until you've tried the non-destructive options first.

Before you do anything: copy what you can

If the drive opens at all — even slowly, even with errors — drag your important files off it now. A failing flash chip can flip from "barely working" to "completely dead" between two double-clicks. Copy first, fix second.

If File Explorer refuses to open the drive at all, skip to the recovery section at the end of this guide before running any of the repair commands below.

Fix 1 — CHKDSK (the safe first attempt)

CHKDSK is built into Windows and repairs file-system corruption without erasing data. It's the right starting point for almost every "corrupt and unreadable" error.

  1. Press Win + S, type cmd, right-click Command Prompt → Run as administrator.
  2. Type the command, replacing F: with your drive letter:
chkdsk F: /F /R /X
  • /F — fix errors it finds.
  • /R — locate bad sectors and recover readable information.
  • /X — force-dismount the volume first so other processes can't keep handles open.

A clean run finishes with "Windows has made corrections to the file system". You can usually open the drive normally afterwards. If CHKDSK errors out with "Cannot open volume for direct access" or refuses with "the type of the file system is RAW", move on.

Fix 2 — Refresh the partition (Disk Management)

Some "corruption" is just a confused partition table. Disk Management can sometimes fix it without a full wipe.

  1. Press Win + X → Disk Management.
  2. If the partition is shown but has a question mark next to its size, right-click → Change Drive Letter and Paths → assign a fresh letter.
  3. If you see "unallocated" across the whole disk, the partition entry is gone — do not create a new one yet (that will overwrite the directory). Run a recovery scan first.

Fix 3 — Quick format (only after backing up)

A quick format rewrites the file-system header without touching the data sectors. It's fast and almost always works on logically corrupted drives — but it does mark every file as deleted, so treat it as a one-way trip unless you've copied your files elsewhere. 

format F: /FS:FAT32 /Q /V:USB

Or, in USB Fix Tool:

  1. Select the drive.
  2. Pick the file system (FAT32 for compatibility, exFAT for files larger than 4 GB, NTFS for Windows-only sticks).
  3. Tick the confirmation checkbox → click Format.

Which file system should I pick?

  • FAT32 — universal, but cannot store single files larger than 4 GB. Ideal for sticks under 32 GB used with TVs, car stereos and old game consoles.
  • exFAT — modern, supports huge files, works on Windows and macOS. Best default for general-purpose USB sticks.
  • NTFS — Windows-native, supports permissions and journaling. Use it for Windows-only sticks (e.g. PC backups).

Fix 4 — Full diskpart rebuild

If even formatting fails ("Windows was unable to complete the format"), the partition table is so damaged that the OS can't place a new file system. Diskpart wipes it and rebuilds from scratch. 

diskpart
list disk
select disk N
attributes disk clear readonly
clean
create partition primary
active
format fs=exfat quick
assign
exit

The same script lives behind the Advanced Repair button in USB Fix Tool, with an extra confirmation step so you don't accidentally clean your boot drive.

Triple-check the disk number. list disk shows every disk in the system. Match the size carefully — selecting the wrong one will erase your operating system.

Fix 5 — Vendor low-level format tools

For SanDisk, Kingston, Transcend and other major brands, the manufacturer's own "low-level format" tool sometimes recovers drives that Windows refuses entirely. They generally erase the flash chip's controller state, which clears stuck write-protect flags. Use these only after the steps above have failed.

If your data was on the drive

Format and diskpart both wipe the visible directory. The actual data is still on the flash chip until something overwrites it — which is why dedicated recovery software can pull files back hours, days, even weeks after a format. The catch: every minute you keep using the drive, the recovery rate drops.

Run a recovery scan first

If you've already formatted the drive, stop writing to it and run a recovery scan now. Modern tools recover photos, Office documents and videos with surprisingly high success rates.

Avoiding corruption next time

  • Always use Eject (or "Safely remove") before unplugging.
  • Don't leave a USB stick in a hot car — flash chips tolerate heat poorly.
  • Buy from reputable sellers — counterfeit drives are the #1 cause of "0 bytes" reports.
  • If you carry the same stick between Windows and macOS, format it as exFAT.
  • Keep a copy of USB Fix Tool on a working stick. When the next one fails you'll be five minutes away from a fix.

Recap

  1. Copy off any readable files first.
  2. Run chkdsk /F /R /X.
  3. Quick-format with the right file system.
  4. Rebuild with diskpart if format fails.
  5. Recover lost files with dedicated software if needed.

Done in order, this works on the overwhelming majority of "corrupted" USB drives — without paying a cent for software you didn't already have on your PC.

Frequently asked questions

How long does CHKDSK take on a USB drive?

A clean 32 GB stick typically finishes in two to five minutes. If you add the /R flag and the drive has many bad sectors, expect 30 minutes to several hours — CHKDSK has to read every sector, retry failures and remap them. Larger drives scale roughly linearly.

Should I use quick format or full format?

For a healthy drive that's just become corrupt, quick format is fine and ten times faster. Full format additionally writes zeros to every sector — useful if you suspect bad blocks (it forces the controller to remap them) or if you're handing the drive on to someone else.

Can I repair a write-protected USB drive?

Check the physical lock switch first (SD cards mostly). If there's no switch, run diskpart and execute attributes disk clear readonly on the selected disk — that's the line USB Fix Tool's Advanced Repair runs automatically. If the read-only state survives, the drive's controller has flipped its own write-protect flag and you'll need a vendor low-level format utility.

Why does my USB drive keep getting corrupted?

The two most common causes are unsafe ejection (always use Eject in the system tray) and counterfeit drives that silently drop writes once you exceed their real capacity. If a drive corrupts repeatedly within weeks of a fix, it's almost certainly a fake — replace it.
