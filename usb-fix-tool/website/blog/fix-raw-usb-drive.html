Fix RAW USB Drive Without Losing Data

Windows wants to format your USB stick before you can use it. Don't. A RAW drive almost always still contains your files — but a quick format will erase the partition entry and slash your recovery odds. This guide shows the right order: recover first, repair second.

What does RAW even mean?

RAW isn't a file system in itself. It's what Windows reports when it can read the drive but can't recognise the file-system header — NTFS, FAT32 and exFAT all start with a specific signature, and when those bytes get corrupted, Windows shrugs and labels the partition RAW.

The most common signs:

  • Double-clicking the drive prompts "You need to format the disk before you can use it".
  • Drive properties show file system as RAW, used and free space both at 0 bytes.
  • CHKDSK refuses with "The type of the file system is RAW. CHKDSK is not available for RAW drives".
  • dir in command prompt returns nothing or "The volume does not contain a recognized file system".

Crucially, your files are usually still on the drive. Only the small header that describes "where the files start" is gone. The data sectors themselves remain intact until something overwrites them — which is exactly what a format does.

Do NOT click "Format disk" in the prompt that Windows shows. Close it. Every minute matters less than the order of operations: recover first, repair second.

Step 1 — Stop using the drive

Don't copy anything onto it. Don't try to "save" it by writing test files. Don't run defrag. Anything you write may overwrite the very sectors a recovery tool needs to read.

Eject the drive cleanly and leave it unplugged until you have a recovery tool ready.

Step 2 — Run a recovery scan first

For RAW drives, recovery software is the right first step — not the last. Modern recovery tools include a "deep scan" mode that walks the drive sector by sector and reconstructs files by their signatures (JPG headers, DOCX zip markers, MP4 boxes, and so on). They don't need a working partition table.

The basic procedure looks the same in every tool:

  1. Install the recovery software on your PC's main drive — never on the broken USB.
  2. Select the RAW USB drive as the source.
  3. Choose deep scan or signature recovery mode.
  4. Wait. A 32 GB stick takes 15–60 minutes depending on speed.
  5. Save the recovered files to a different drive. Never save them back to the RAW USB.

Recover before you repair

Recovery software for RAW drives is mature and surprisingly good. Photos, Office documents, MP4 videos and PDFs come back with high success rates — provided you scan before you format.

Step 3 — Try the non-destructive repair (TestDisk)

Sometimes the partition entry itself is fine and only the boot sector is corrupted. TestDisk (free, open source) can rebuild that header and bring the drive back as a normal NTFS / FAT32 partition with all your files still in place.

  1. Download TestDisk from cgsecurity.org.
  2. Run testdisk_win.exe as administrator.
  3. Choose "No log", select your USB drive, then "Intel" partition table type for most modern sticks.
  4. Pick "Analyse" → "Quick Search".
  5. If the partition is found, press P to list files. If you see your folders, the drive is fine — press Enter, then "Write", then reboot.

TestDisk has saved more RAW drives than any other tool — and it doesn't write to the data sectors at all. It's the safest second attempt after a recovery scan.

Step 4 — Convert RAW to NTFS / FAT32 with format

Once you have your files safely backed up elsewhere, you can return the drive to a usable state with a quick format. This is the only destructive step, and you should only run it after Steps 1–3. 

format F: /FS:NTFS /Q /V:USB

Or, in USB Fix Tool: select the drive → pick NTFS or exFAT → tick the confirmation checkbox → click Format. The full output is logged so you can check that the format completed cleanly.

Which file system?

  • exFAT — works on Windows and macOS, supports large files. Best default for general-purpose USB sticks.
  • NTFS — Windows-native, supports permissions, slightly more robust against power-loss corruption.
  • FAT32 — universal compatibility (TVs, car stereos, retro consoles), but capped at 4 GB per file.

Step 5 — Diskpart rebuild (if format fails)

If format errors out with "Windows was unable to complete the format" or "The media is write protected", the partition table itself is broken. A diskpart clean rebuilds everything from scratch. 

diskpart
list disk
select disk N
attributes disk clear readonly
clean
create partition primary
active
format fs=exfat quick
assign
exit

Same script, available as the Advanced Repair button in USB Fix Tool, with built-in confirmation dialogs so you can't pick the wrong disk by accident.

How does a USB drive even go RAW?

  • Yanking the stick out during a write or copy operation.
  • Unplugging while Windows Defender is mid-scan.
  • Power loss during a format.
  • Aging NAND cells flipping individual bits in the file-system header.
  • Malware that damages partition entries.

Always use the system tray's Eject option before pulling a USB stick. It takes two seconds and prevents the most common cause of RAW drives.

Recap — the RAW playbook

  1. Stop writing. Eject and leave the drive alone.
  2. Recover your files. Deep-scan with a recovery tool, save results to another drive.
  3. Try TestDisk. Non-destructive partition repair brings many RAW drives back intact.
  4. Quick format the drive once your data is safe.
  5. Diskpart rebuild if format itself fails.

Done in this order, RAW is one of the most recoverable USB failures — most users keep their files and their drive. Skip step 2, and you'll keep neither.

Frequently asked questions

Is RAW the same as "unformatted"?

Almost. RAW means Windows can talk to the drive but doesn't recognise the file-system header. An "unformatted" drive typically has no partition at all — just unallocated space. Both show as inaccessible in File Explorer; both can be fixed without erasing data if you act before formatting.

Why does my brand-new USB suddenly show as RAW?

Most often: unsafe ejection during a write, or a power glitch on the USB port. The drive was mid-update of the file-system header when power dropped, leaving it in a half-written state Windows can't parse. The data sectors are usually fine — only the metadata is broken.

Can CHKDSK fix a RAW drive?

No — CHKDSK explicitly refuses to run on RAW partitions. It needs a recognisable file system to repair. Use TestDisk first (non-destructive), recover files with dedicated software, and only then format the drive to bring it back to a usable state.

Will a quick format on a RAW drive let me recover files?

Maybe — recovery rates after a quick format on a previously RAW drive are noticeably lower than recovery from RAW directly. The quick format writes a new file-system header on top of the data and creates a fresh root directory entry, which can overwrite metadata recovery tools rely on. Always recover before you format.

Is TestDisk safe to use?

Yes. Until you actually press Write, TestDisk only reads from the drive. Even at the Write step, it only modifies the partition table and boot sector — it never touches data. It's been a free standard tool in data recovery since 2003, with no track record of damaging drives.
